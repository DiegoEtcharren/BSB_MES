# Manufacturing Execution System (MES)

## Project Description
The idea of this project is a manufacturing system, where all the information of the process can be logged into the system, making sure that the specifications for each type of product are followed properly.

## Tech Stack
* **Backend:** Laravel
* **Frontend:** React
